
# Dialog Saver React App

This is a simple React app created with Vite. It allows you to enter text in a textarea and add it as a saved dialog below. Each dialog you add will appear in a list under the textarea.

## Features
- Textarea for entering any text
- 'Add' button to save the text
- List of saved dialogs displayed below the textarea

## Getting Started

1. **Install dependencies:**
   ```sh
   npm install
   ```
2. **Start the development server:**
   ```sh
   npm run dev
   ```
3. Open your browser to the local address shown in the terminal (usually http://localhost:5173).

## Project Structure
- `src/App.jsx`: Main component with textarea, add button, and dialog list
- `src/main.jsx`: Entry point using ReactDOM

---
This project was bootstrapped with [Vite](https://vitejs.dev/) and uses React 18.
